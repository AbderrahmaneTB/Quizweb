# Neon Trivia Quiz 🎮✨

A full-stack, timed trivia application featuring a stunning neon glassmorphism UI, real-time countdowns, and persistent score tracking.

## 🌟 Features

* **Modern Glassmorphism UI:** Beautiful, responsive design using CSS variables, custom animations, and backdrop filters.
* **User Authentication:** Secure login and account creation system.
* **Dynamic Trivia:** Fetches random, easy-difficulty multiple-choice questions from the [Open Trivia Database (OpenTDB)](https://opentdb.com/).
* **Real-Time Timer:** An animated SVG circular countdown timer that turns red as time runs out (10 seconds per question).
* **High Score Tracking:** Automatically saves and retrieves your maximum score from the custom backend database.

## 🛠️ Tech Stack

* **Frontend:** React, Next.js, standard CSS (Glassmorphism theme)
* **Backend:** Node.js (running on port 3001)
* **HTTP Client:** Axios (configured with credentials for secure sessions)
* **External API:** OpenTDB API
